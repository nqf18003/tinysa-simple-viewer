# tinySA シンプル ビューア

[English version](README.en.md)

### [⬇ ダウンロード（最新版の exe）](https://github.com/nqf18003/tinysa-simple-viewer/releases/latest)
リンク先のページの下にある **Assets** の `tinySA_Simple.exe` を押すとダウンロードできます。

スペクトラムアナライザー **tinySA Ultra / Ultra+** 用の、Windows で動く最小限のビューアです。
tinySA を USB でつなぐと、本体と同じ掃引をパソコンに表示します。マーカーは 4 つまで使えます。
画面の文字は英語です（英語圏の人にも使ってもらうため）。

- 表示する周波数の範囲と縦軸は、本体の設定に合わせます。
- 周波数の範囲・RBW・アッテネーター・External gain・MAX HOLD は、パソコンからも変えられます。
- グラフの右上に、測定条件（周波数の範囲・RBW・アッテネーター・External gain・日時）を表示します。
- 占有周波数帯幅の目安になる点線を引けます。
- **Pause** で、本体とグラフを今の掃引のところで止められます。
- マーカー M1〜M4 はマウスで置き、矢印キーで動かします。本体のマーカーとアプリのマーカーは、どちらで動かしてもそろいます。
- 本体の画面とグラフを PNG 画像で保存できます。

> **大切: 最新のファームウェアを使わないと、使えない場合があります。**
> 使う前に、tinySA を最新のファームウェアに更新してください。
>
> **テストした機種:** tinySA Ultra+ の **ZS406** と **ZS407**（ファームウェア v1.4-266）。ほかの機種ではテストしていません。
>
> このビューアは、ファームウェア **v1.4-216 以降**で一番よく動きます。新しいファームウェアには
> `waitscan` 命令があり、本体の掃引が終わってから読めるので、本体の掃引が毎回最後まで終わります。
> 古いファームウェアでは読むタイミングを推測するため、掃引が途中で切れたり、本体がときどき応答しなくなったりすることがあります。
> ファームウェアと更新のしかた: https://tinysa.org/wiki/

## 必要なもの
- Windows 10 / 11
- tinySA Ultra または Ultra+（ZS406・ZS407 で確認）
- USB ケーブル（データ通信ができるもの）

## 起動
### exe で使う
1. [最新版のページ](https://github.com/nqf18003/tinysa-simple-viewer/releases/latest)から `tinySA_Simple.exe` をダウンロードします。
2. ダブルクリックで起動します。インストールは要りません。
   - 初めて起動するとき、Windows が「**Windows によって PC が保護されました**」（SmartScreen）と出すことがあります。
     exe に電子署名がないためです。「**詳細情報**」を押してから「**実行**」を押してください。

### Python で使う
1. Python 3.12 以降を入れます。
2. このフォルダで次を実行します。
   ```
   python -m pip install -r requirements.txt
   python tinysa_simple.py
   ```

## 使い方
1. **Port** で tinySA の COM ポートを選び、**Connect**（接続）を押します。
   - 一覧に無いときは **Refresh**（更新）を押します。
   - **Dummy (no device)** を選ぶと、実機なしで試せます。
2. グラフに本体の掃引が表示され、本体の掃引が 1 回終わるたびに更新されます。
   - 本体で範囲や基準レベルを変えたときも、掃引 1 回分ほどでパソコンに反映されます。
   - 上の欄に、機種・ハードの版・ファームウェアの版が出ます。
   - 掃引が遅い設定（範囲が広い・RBW が狭い）では、パソコンの更新もゆっくりになります。
   - 横軸の数字は、いつも周波数そのもの（MHz）です。範囲が狭いときは、小数点以下の桁が増えます。
   - グラフの右上に、周波数の範囲・RBW・アッテネーター（Atten）・External gain（ExtGain）・今の日時（分まで）を表示します。
     周波数の範囲は、**Settings...** で選んだ形（中心 + Span か Start + Stop）で出します。最初は Start + Stop です。
     ExtGain は本体から読めないので、このアプリで設定した値を出します（まだ設定していないときは unknown）。
3. **本体の設定**（接続中だけ使えます）
   - **Settings...** … 本体の今の設定が入った画面が開きます。
     - 周波数の範囲は、**Center / Span**（中心 MHz と Span kHz）か **Start / Stop**（MHz）のどちらかで入力します。
     - **RBW** は、本体のメニューと同じ選択肢から選びます。選択肢は機種に合わせて変わります
       （Ultra: AUTO / 200 / 1k / 3k / 10k / 30k / 100k / 300k / 600k / 850k）。
     - **Attenuation**（内部アッテネーター）は、一覧（AUTO / 0 / 5 / … / 30 dB）から選ぶか、0〜30 の整数を直接入れます。
     - **External gain**（外付けアッテネーターなどの補正）は、−100〜100 dB の数字を入れます。本体からは今の値を読めないので、
       前にこのアプリで設定した値が入っています（機種ごとに、exe と同じ場所の `tinysa_simple_settings.json` に覚えます）。
       空欄のまま OK を押すと、本体の値は変えません。本体で自己診断や校正をすると 0 に戻るので、そのときは入れ直してください。
     - **OK** で本体に設定します。RBW と Attenuation は、変えたときだけ送ります（本体の AUTO が外れないように）。**Cancel** では何も変えません。
   - **Max hold** … チェックを入れると本体の MAX HOLD がオン、外すとオフになります。
     切り替えるたびに、グラフと保持していた最大値を消し、最初から測り直します。
     本体で MAX HOLD を切り替えたときも、チェックが本体に合わせて変わります。
   - **Pause** … 今の掃引が終わったところで、本体とグラフが止まります（ボタンは **Resume** に変わります）。
     **Resume** でまた動きます。止めても再開しても、MAX HOLD は消えません。
     止めている間も、マーカーの操作・本体のマーカーとの連動・画像の保存はできます。止めている間に設定を変えると、自動で再開します。
   - 設定を変えると、グラフはいったん消え、新しい設定での掃引が終わると表示されます。
4. **占有周波数帯幅の目安線**
   - **Bandwidth lines** で幅を選ぶと（0 = 線なし、0.5 / 3 / 6 / 30 / 40 kHz）、表示範囲の中心 ± 幅の半分のところに、縦の点線を 2 本引きます。
     例: 6 kHz なら中心 ± 3 kHz。
5. **マーカー（4 つまで）**

   | すること | 操作 |
   |---|---|
   | マーカーを選ぶ | **M1〜M4** のボタンか、キーボードの **1〜4** |
   | 置く | グラフをクリック |
   | 1 点ずつ / 10 点ずつ動かす | **← →** / **Shift + ← →** |
   | 消す | **Delete** キーか **Clear selected marker** |

   - グラフの下に、各マーカーの周波数とレベルを表示します。
   - **本体のマーカーとアプリのマーカーは両方向でそろいます。** アプリで M1〜M4 を置く・動かす・消すと本体の同じ番号のマーカーも、
     本体で動かす・増やす・消すとアプリのマーカーも、掃引の合間に同じようになります。
     本体がピークを自動で追うマーカー（1T など）は、アプリでも掃引のたびに動きます。本体の M5〜M8 はアプリには出しません。
6. **画像の保存**。exe（または `tinysa_simple.py`）と同じ場所の `captures` フォルダに、日時の名前で保存します。
   - **Save device screen** … 本体の画面（480 × 320）を保存します。掃引の合間に取り込むので、本体もアプリも止まりません。
   - **Save graph** … グラフを、測定条件・目安線・機種・日時・マーカーの値と一緒に保存します。ウィンドウの大きさに関係なく、いつも 1200 × 800 ピクセルです。
   - 保存した場所は、ウィンドウの右下に出ます。
7. 終わるときは **Disconnect**（切断）を押すか、ウィンドウを閉じます。

## 注意
- **接続中も本体の MAX HOLD が使えます**（本体でも **Max hold** のチェックでも切り替えられます）。ただし **Disconnect** を押すと本体を通常の掃引に戻すので、そのとき MAX HOLD は消えます。
- 接続中、本体の画面に **PAUSED**（一時停止）と出ることがあります。故障ではなく、掃引は続いています。
- tinySA は命令を受けるたびに掃引を最初からやり直します。このビューアは掃引の合間にだけ命令を送ります。
- **「The tinySA is not responding」**（本体が応答しません）と出たら、Disconnect を押し、USB を抜いて本体の電源を入れ直してから、もう一度つないでください。

## データの保存先・送り先
- tinySA とのやりとりは USB だけです。インターネットには何も送りません。
- 保存した画像は、パソコンの `captures` フォルダだけに置きます。
- External gain の値は、パソコンの `tinysa_simple_settings.json`（exe と同じ場所）だけに覚えます。
- 通信のトラブルがあったときだけ、原因を調べるために exe と同じ場所の `error_log.txt` に記録します。
